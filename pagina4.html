Conceptos Básicos

  • Dominio:

    En HTML, el término "dominio" se refiere al nombre de dominio de un sitio web, que es la dirección que los usuarios escriben en la barra de navegación para acceder a él.

  • Subdominio:

    En HTML, un subdominio no se define directamente. Un subdominio es una dirección web que forma parte de un dominio principal, como "blog.ejemplo.com", donde "blog" es el subdominio y "ejemplo.com" el dominio principal.

  • URL:

    En HTML, una URL (Uniform Resource Locator) es la dirección que identifica un recurso específico en la web.

  • DNS:

    En HTML, DNS se refiere al Sistema de Nombres de Dominio (Domain Name System), una parte fundamental de la web que traduce nombres de dominio (como www.google.com) a direcciones IP (como 74.125.19.147) que los navegadores utilizan para conectar con los servidores web.

  • Hosting:

    En HTML, el "hosting" o "alojamiento web" se refiere al servicio que permite almacenar los archivos de un sitio web (como archivos HTML, CSS, JavaScript, imágenes, etc.) en un servidor conectado a internet.

  • FTP:

    En HTML, FTP (File Transfer Protocol) no es una etiqueta ni un elemento, sino una forma de interactuar con un servidor web para subir y descargar archivos.

  • HTTP:

    HTTP, que significa Hypertext Transfer Protocol (Protocolo de Transferencia de Hipertexto), es el protocolo que se utiliza para transferir documentos hipermedia, como HTML, a través de la World Wide Web.

  • HTTPS:

    HTTPS es la versión segura de HTTP (Hypertext Transfer Protocol), que se utiliza para transferir datos entre un navegador web y un servidor web. La "S" significa "seguro" y la comunicación entre el navegador y el servidor está cifrada, lo que significa que la información transmitida no puede ser leída por terceros.

  • W3C:

    W3C, que significa World Wide Web Consortium, es una organización internacional que desarrolla estándares y directrices para la Web, incluyendo HTML, CSS y otros lenguajes y tecnologías. Su objetivo es asegurar que la Web siga siendo accesible, interoperable y segura para todos,.

  • UTF-8:

    En HTML, UTF-8 es la codificación de caracteres más común, que se utiliza para representar texto en páginas web. Es una forma de codificar los caracteres de diferentes idiomas y símbolos, permitiendo que los navegadores los interpreten correctamente.

  • HTML5 y su estructura:

    HTML5 es la última versión del lenguaje de marcado HyperText Markup Language (HTML), usado para estructurar el contenido de las páginas web. Su estructura básica incluye una declaración de tipo de documento (), un elemento raíz (), y secciones para encabezado () y cuerpo ().
